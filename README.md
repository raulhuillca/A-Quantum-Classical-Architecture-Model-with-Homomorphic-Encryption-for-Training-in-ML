# A Quantum-Classical Architecture Model with Homomorphic Encryption for Training and Privacy Preservation in Machine Learning

This repository contains the experimental implementation of the research project: **"A Quantum-Classical Architecture Model with Homomorphic Encryption for Training and Privacy Preservation in Machine Learning."**

The proposed architecture integrates the **Quantum Fourier Transform (QFT)** with the **CKKS homomorphic encryption scheme** to investigate privacy-preserving machine learning over frequency-domain representations.

## Experimental Pipeline

The experimental pipeline combines the following stages:

* Classical preprocessing
* Quantum feature transformation
* Homomorphic encryption
* Machine learning
* Quantitative evaluation
